# منظومة فحص رصانة البحوث العلمية
### جامعة الكوفة - كلية التخطيط العمراني

بوابة إلكترونية لتدقيق وفحص رصانة النتاج العلمي للترقيات العلمية وتقييم الأداء.

- **الموقع المباشر**: [https://st.physplan.com](https://st.physplan.com)
- **جدول البيانات المرتبط**: [Google Sheets](https://docs.google.com/spreadsheets/d/1O0DW0SLDjbf2TRlvxez6u5pkezi9fbctgH9QPLwC1qw/edit)

### مميزات المنظومة:
1. تسجيل دخول التدريسيين عبر الهاتف ورمز OTP عبر واتساب.
2. اختيار القسم العلمي (التخطيط الحضري، البيئي، الإقليمي).
3. استمارة إدخال بيانات البحث بالمدخلات الـ 11 المعتمدة.
4. حسابات مستقلة ومحمية لمخولي الأقسام الثلاثة.
5. اعتماد الأوامر الإدارية وتصدير محضر الفحص الرسمي بصيغة PDF.
